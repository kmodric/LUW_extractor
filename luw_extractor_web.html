SM58 LUW File Extractor

Standalone HTML/JavaScript tool for extracting a file from a saved SAP SM58 LUW log. Everything runs locally in your browser; the input file is not uploaded anywhere.

Click here or drop a .txt/.log file
You can also paste the full SM58 log content into the text area below.

The tool automatically adds .pdf when the extracted bytes start with %PDF; otherwise it adds .txt.

Download result
Load or paste an SM58 log, then click Extract file.

What this tool does

It finds SAP rows such as binary 25504446..., joins the hex values, converts them to bytes, detects whether the result is a PDF, and creates a local download. For PDF output, auto mode trims from %PDF to the last %%EOF marker.

Note: the browser cannot read SM58 directly from SAP GUI/RFC. You still need to save or copy the SM58 display data into a text file first.

Instructions
  1. Open SM58 in SAP and display the Transaction ID / LUW data.
  2. Save the display as .txt or copy the full text.
  3. Load the file here, or paste the text into the text area.
  4. Click Extract file.
  5. Download the result and compare the displayed hashes if needed.
Mapping to the old C# tool
  • The old tool waited for the second Line-No: 00000001.
  • After that, it took hex data from rows containing binary.
  • This version keeps that compatible mode, but the default auto mode is safer because it searches for the actual %PDF signature.
  • If no PDF signature is found, the extracted bytes are still downloadable as .txt.
